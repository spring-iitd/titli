**Added:**

* Initial PyPI release

* Multiple IDS models (KitNET, LOF, OCSVM, Autoencoder, VAE, ICL)
* PyTorch and scikit-learn implementations
* Streaming CSV dataset support
* RMSE loss function

* IDS models: KitNET, TorchKitNET, PyTorchKitsune, LOF, OCSVM, Autoencoder, VAE, ICL
* Utilities for data handling and loss computation
